# Engiverse – Marketplace for Unfinished Projects

**An Academic Software Project**

## Project Overview

Engiverse is a web-based platform developed to explore the concept of a structured marketplace for unfinished software projects. It aims to facilitate the discovery, evaluation, and further development of student-created software projects by connecting project creators with interested individuals and organisations.

The project explores the integration of marketplace functionality, repository-based project assessment, artificial intelligence-assisted insights, and collaborative development capabilities.

## Technology Stack

The project utilises modern web development technologies, backend frameworks, database systems, and third-party integrations.

- **Frontend:** Next.js, React, Tailwind CSS
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **ORM:** SQLAlchemy
- **Repository Integration:** GitHub API
- **Payment Integration:** Cashfree
- **AI Integration:** AI-assisted analysis and insights

## Key Areas of Development

- Project discovery and marketplace functionality
- Repository-based project assessment
- AI-assisted project insights
- Collaboration and contributor engagement
- Project lifecycle and milestone management
- Role-based platform access
